# Security policy

This repository is a research prototype and is not designed for safety-critical
or adversarial radio environments.

Please report a vulnerability privately to the repository owner through
GitHub's private vulnerability reporting feature. Do not include credentials,
private RF captures, personal images, or exploitable details in a public issue.

Only the latest commit on the default branch is maintained. Dependency and
vendor-runtime vulnerabilities should also be reported to the relevant upstream
project (NVIDIA JetPack/TensorRT, Ettus UHD, TensorFlow, PyTorch, or Sionna).
